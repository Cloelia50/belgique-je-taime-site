Saint-Gilles — prime pour un tonneau récupérateur d’eau de pluie

Piste à vérifier, pas un droit personnel confirmé. Les conditions, montants et délais dépendent de votre situation.

Saint-Gilles maintient une procédure communale de prime pour l’achat d’un tonneau récupérateur d’eau de pluie. Cela permet de réduire l’utilisation d’eau potable pour l’arrosage ou le nettoyage. Le montant doit être vérifié dans le règlement courant avant l’achat.

Conditions ou organisme : Commune de Saint-Gilles — primes environnement.

Quand s’y intéresser : Avant ou juste après l’achat : consultez d’abord le règlement actuel afin de confirmer l’éligibilité du matériel.

Comment procéder

  1. Lisez le règlement actuel et vérifiez le type de tonneau accepté.
  2. Achetez le matériel seulement après avoir vérifié les conditions si la prime est déterminante.
  3. Conservez facture/ticket.
  4. Introduisez la demande via le formulaire communal.

Documents éventuels

  • Preuve d’achat.
  • Pièces prévues par le règlement communal.
