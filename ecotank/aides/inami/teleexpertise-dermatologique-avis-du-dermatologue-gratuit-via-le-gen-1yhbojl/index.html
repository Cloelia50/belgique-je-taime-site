Téléexpertise dermatologique : avis du dermatologue gratuit via le généraliste

Piste à vérifier, pas un droit personnel confirmé. Les conditions, montants et délais dépendent de votre situation.

Depuis le 1er septembre 2026, un médecin généraliste peut demander à distance l’avis d’un dermatologue sur une lésion cutanée. Pour le patient, cette téléexpertise est gratuite et peut éviter une consultation spécialisée immédiate lorsqu’elle n’est pas nécessaire.

Conditions ou organisme : Médecin généraliste → dermatologue participant.

Quand s’y intéresser : Lorsqu’un généraliste souhaite un avis spécialisé sur une lésion cutanée avant d’orienter éventuellement vers une consultation physique.

Comment procéder

  1. Montrez la lésion à votre généraliste.
  2. Demandez si une téléexpertise dermatologique est adaptée.
  3. Le généraliste transmet les informations nécessaires au dermatologue.
  4. Le généraliste reçoit l’avis et vous explique la conduite à tenir.
  5. Prenez un rendez-vous physique uniquement si l’avis ou l’évolution le justifie.

Documents éventuels

  • Aucun document administratif spécifique pour le patient.

Contact

Votre médecin généraliste.
