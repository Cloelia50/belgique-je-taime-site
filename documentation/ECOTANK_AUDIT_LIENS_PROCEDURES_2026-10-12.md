# EcoTank — Audit des liens et aboutissement des procédures (12 octobre 2026)

## Critère de réussite
Un lien est **VALIDÉ** seulement si une page spécifique et pertinente a été consultée, si ses conditions et étapes sont comprises, si les documents / délais / canaux d'introduction sont indiqués et si un point de suivi est disponible. Un lien présent dans le code ou un test JavaScript n'est **pas** une validation du site publié ni de l'issue administrative.
