Signaler une erreur

Quelque chose a changé ? Dites-le-nous.

Un événement annulé, une mauvaise date, un lien cassé, une aide supprimée, un montant qui a changé ou un problème technique : un signalement permet de vérifier plus vite l’information à sa source.

Ne publiez aucune donnée personnelle ou sensible. Pas de numéro de registre national, revenu, dossier médical, adresse privée, code itsme/eID, mot de passe ni document administratif. Le canal actuel de signalement passe par le dépôt public GitHub du projet : le contenu du signalement peut donc être visible publiquement.

Ce qui aide le plus

  • le nom de la page ou de l’événement concerné ;
  • l’adresse de la page Belgique, je t’aime où vous avez vu le problème ;
  • ce qui semble faux ou dépassé ;
  • si vous l’avez, le lien vers la source officielle qui permet de vérifier.

Ouvrir le formulaire de signalement sur GitHub →

GitHub demande actuellement un compte pour envoyer le signalement. C’est le canal gratuit disponible aujourd’hui ; un canal sans compte reste à mettre en place avant un lancement à très grande échelle.
