Vie privée

Dire exactement ce qui se passe.

Pas de compte utilisateur. Belgique, je t’aime ne vous demande pas de créer un profil en ligne pour utiliser Activikids, Écotank ou Cogito. Les réponses du parcours administratif récent d’Écotank ne sont pas envoyées à un serveur de Belgique, je t’aime.

Ce qui peut rester sur votre appareil

Plusieurs fonctions utilisent le stockage local du navigateur pour que le site se souvienne de vos choix. C’est notamment le cas de certains favoris et préférences d’Activikids, des favoris de Cogito et du tableau de bord historique d’Écotank (profil de recherche, suivi de démarches, gains saisis et états de suivi). Ces données restent dans le navigateur utilisé et peuvent être effacées en supprimant les données du site dans les réglages du navigateur.

Écotank comporte aussi un parcours administratif plus récent conçu pour guider des situations potentiellement sensibles sans conserver ses réponses dans ce stockage local. Ne saisissez jamais de code PIN eID, code itsme, mot de passe, numéro complet de registre national ou autre secret.

Hébergement du site

Le site public est hébergé par GitHub Pages. GitHub indique que, lors de la visite d’un site Pages, l’adresse IP du visiteur est journalisée et conservée à des fins de sécurité, qu’il soit connecté à GitHub ou non. Ce traitement relève de l’hébergeur. Belgique, je t’aime ne demande pas cette adresse et ne l’ajoute pas à un profil utilisateur.

Voir l’explication de GitHub Pages sur l’hébergement et les données techniques.

Mesure d’audience

L’accueil, Activikids et Cogito utilisent une mesure d’audience légère via CounterAPI. Elle sert à compter des visites de rubrique et certains clics sortants. Le site envoie un identifiant de rubrique ou d’événement et le type d’action ; il n’envoie pas à cet outil les réponses Écotank, vos termes de recherche, votre revenu, votre adresse ni le contenu d’un formulaire.

Écotank n’envoie pas de mesure d’audience à CounterAPI. La page Vie privée non plus. Lorsque la préférence « Do Not Track » ou Global Privacy Control est activée dans le navigateur, le script commun n’envoie pas ces mesures.

CounterAPI est un service tiers : comme pour tout appel réseau, son infrastructure peut traiter les informations techniques nécessaires à la connexion. Belgique, je t’aime n’utilise pas ces mesures pour de la publicité ciblée et ne revend pas les données d’usage.

Adresse exacte dans Activikids

Si vous utilisez volontairement la recherche à partir d’une adresse exacte dans Activikids, l’adresse saisie est envoyée au service de géocodage Nominatim d’OpenStreetMap afin d’obtenir des coordonnées. Cette adresse n’est pas envoyée à Belgique, je t’aime pour constituer un profil. Si vous ne souhaitez pas utiliser ce service externe, choisissez simplement une commune ou n’utilisez pas la recherche par adresse.

Liens vers d’autres sites

Quand vous ouvrez le site d’une administration, d’un organisateur, d’une billetterie ou d’un autre service externe, ce site applique sa propre politique de confidentialité. Votre navigateur lui transmet aussi les informations techniques normales nécessaires à l’ouverture d’une page.

Ce que cette page ne promet pas

Il serait inexact d’écrire qu’« aucune donnée ne quitte jamais votre appareil » tant qu’Activikids peut géocoder une adresse et que certaines rubriques utilisent une mesure d’audience externe. L’engagement est donc plus précis : limiter les transmissions, ne pas envoyer les réponses administratives sensibles à l’outil d’audience et expliquer les exceptions.
